✨ Poof Language

Функциональный язык программирования на основе лямбда-исчисления.

📖 Пример

spell fact n ->
  if n == 0 then 1
  else n * (cast fact with n - 1)
whisper (cast fact with 5)  ~~ 120

🚀 Быстрый старт

git clone https://github.com/EkaterinaChukanova/-.git
cd -
dotnet build poof
dotnet run --project poof -- examples/factorial.poof

📚 Синтаксис

КонструкцияПример
Переменнаяbind x to 42
