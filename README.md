**Poof** — функциональный язык программирования на основе лямбда-исчисления.

## Стандартная библиотека

`stdlib/list.poof` содержит утилиты для работы со списками:

| Функция | Описание | Пример |
|---------|----------|--------|
| `fold` | Левая свертка | `fold (x y -> x + y) 0 [1,2,3]` |
| `append` | Объединение списков | `append [1,2] [3,4]` |
| `reduce` | Свертка без начального значения | `reduce (x y -> x + y) [1,2,3]` |

## Встроенные функции

| Категория | Функции |
|-----------|---------|
| Списки | `peek`, `rest`, `conjure`, `isVoid`, `count`, `mirror` |
| Функции высшего порядка | `enchant` (map), `sieve` (filter), `condense` (fold) |
| Математика | `purify` (abs), `unroot` (sqrt), `transmute` (toInt), `dissolve` (toFloat) |
| Строки | `measure` (длина), `inscribe` (toString), `contains` |
| Ввод-вывод | `whisper` (print), `announce` (println), `listen` (readLine) |
| Ленивость | `delay`, `force` |

## Возможности языка

- **Call-by-value** (строгие вычисления) — аргументы вычисляются до вызова
- **Лексические замыкания** — функции захватывают окружение
- **Хвостовая рекурсия** — оптимизация через trampoline
- **Ленивые вычисления** — через `delay`/`force`
- **Полнота по Тьюрингу** — доказана Y-комбинатором
